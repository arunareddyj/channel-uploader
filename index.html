Channel Uploader

A private publishing tool for the operator's own YouTube channels.

Channel Uploader is a small, private tool that uploads videos produced by its operator to YouTube channels that the operator owns and manages. It uses the YouTube Data API to upload videos, set titles, descriptions, thumbnails and publishing schedules, and to mark AI-generated narration as altered or synthetic content.

The tool is not offered to the public and does not access anyone else's account. It is used only with channels whose owner has explicitly authorized it through Google's sign-in.
